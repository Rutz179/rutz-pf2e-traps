# Rutz's Traps

Players set traps the GM can't see; the GM finds out when something steps on one.

- **Hidden player traps** — during trap-setting time, players place snares, traps and poisons from their packs on the map; only they see the markers.
- **Sprung** — the creature stops on the square and the GM gets the trap like a used item, with the DC already applied.
- **GM traps**, and a secret peek at the players' traps.
- **DCs that keep up** — level-based DCs (+2 by default): PF2e GM Core, D&D 5e 8 + proficiency + 3, or a generic rule for other systems.

## Install
Foundry → *Add-on Modules* → *Install Module* → Manifest URL:
```
https://github.com/Rutz179/rutz-pf2e-traps/releases/latest/download/module.json
```
Foundry VTT v13–v14 · PF2e · D&D 5e · any system · English / 한국어

The trap buttons in the token controls, or `game.rutzTraps.open()`.

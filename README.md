# Rutz's PF2e Traps

플레이어들이 GM 몰래 덫·함정·독을 깔아 두는 모듈입니다. GM 화면에는 위치가 보이지 않고, 적이 밟으면 GM에게 아이템을 쓴 것처럼 세부 내용이 뜹니다.

- 파티 가방 속 덫·함정·독·마름쇠를 자동으로 모아 보여 주고, 지도 칸을 눌러 설치
- 레벨에 맞춘 함정 DC (아이템 DC와 레벨 DC + 2 중 높은 쪽 — 설정)
- GM도 함정을 깔 수 있고(아이템·위험 끌어 놓기, 또는 이름과 DC만), 필요할 때 PC 함정을 몇 초간 몰래 볼 수 있음
